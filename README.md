# SHADOWLINE - An AI-Driven Psychological Interactive Fiction Game

An AI-driven psychological interactive fiction game where the player's decisions actually affect what happens next.

### Concept
This project is based on my own idea and combines Python, Tkinter, Google Gemini API, and JSON to create an interactive story with dynamic branching narratives.

### Key Features
- Interactive story where decisions affect outcomes
- Behavioral pattern tracking (trust, fear, curiosity, empathy, honesty, self-control, risk-taking)
- Gemini AI works as an AI game master, generating connected situations and consequences
- Dynamic experience where different decisions lead to different story paths and endings
- Psychological element tracking
- JSON-based save system

### Tech Stack
- Python
- Tkinter (GUI)
- Google Gemini API
- JSON

### How to Run
1. Clone this repository:
   git clone https://github.com/EmanFatima-00/shadowline-ai-interactive-fiction-game.git

2. Install dependencies:
   pip install google-generativeai

3. Add your Gemini API key in the code

4. Run the game:
   python shadowline.py
